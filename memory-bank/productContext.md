# Product context

## Users

Developers embedding Excalidraw and end users drawing on excalidraw.com.

## Experience goals

- Fast canvas editing with predictable state and undo/redo.
- File format compatibility preserved when changing persistence (`restore` and related paths).

## Problems this repo solves

- Single source of truth for the editor component and the production app.
- Shared math, element model, and utilities across packages.
